# SmartMirror Projekt Status

## Allgemeine Informationen

**Projekt:**
SmartMirror

**Ziel:**
Entwicklung eines webbasierten Smart Mirrors auf einem Raspberry Pi Zero 2 W mit einer modularen Architektur.

* Display mit HDMI-Controller
* Raspberry Pi OS Lite (64 Bit)

## Kapitel 6 – Wettermodul

**Status:**
✅ Abgeschlossen

### Wetter-API

OpenWeather API wurde integriert.

Die API-Anfrage erfolgt über:

```text
Browser
    │
    ▼
weather.js
    │
    ▼
api/weather.php
    │
    ▼
OpenWeather API
```

### Sicherheitskonzept

Der API-Key wird nicht direkt im öffentlich erreichbaren Code gespeichert.

Verwendet wird:

```text
config/secrets.php
```

Die Datei wird nicht in das Git-Repository übertragen.

### Wetterdaten

Das Modul zeigt aktuell:

* [x] Standort
* [x] Aktuelle Temperatur
* [x] Gefühlte Temperatur
* [x] Wetterbeschreibung
* [x] Wetter-Icon
* [x] Luftfeuchtigkeit
* [x] Windgeschwindigkeit
* [x] Zeitpunkt der letzten Aktualisierung

### Wetter-Cache

Ein Cache-System wurde implementiert.

Die Wetterdaten werden in:

```text
cache/weather.json
```

gespeichert.

Die Cache-Dauer beträgt aktuell:

```text
600 Sekunden
```

also:

```text
10 Minuten
```

### Cache-Ablauf

```text
Wetteranfrage
      │
      ▼
Cache vorhanden und jünger als 10 Minuten?
      │
      ├── Ja
      │    │
      │    └── weather.json verwenden
      │
      └── Nein
           │
           ▼
      OpenWeather API
           │
           ▼
      Neue Daten speichern
           │
           ▼
      weather.json
```

### Rechte

Der Cache-Ordner ist für PHP-FPM beschreibbar.

Der PHP-FPM-Benutzer:

```text
www-data
```

kann die Datei:

```text
cache/weather.json
```

erstellen und aktualisieren.

### Automatische Aktualisierung

Das Wettermodul ruft die Wetterdaten aktuell alle:

```text
10 Minuten
```

neu ab.

